# VK-бот «Калькулятор единиц измерения»

Бот для сообщества ВК: переводит длину, площадь и объём между единицами.
Работает через Long Poll — публичный IP и HTTPS не нужны.

## Состав проекта

```
VK_бот/
├── .env                  # токен сообщества (не коммитить!)
├── .env.example          # образец файла с токеном
├── requirements.txt      # зависимости
├── start_bot.bat         # запуск бота двойным кликом
├── venv/                 # виртуальное окружение
└── VK_бот/
    ├── main.py           # сам бот
    ├── config.py         # загрузка токена из .env
    ├── diag.py           # проверка токена и настроек Long Poll
    └── diag_poll.py      # ручное прослушивание событий (отладка)
```

## Быстрый запуск

1. Убедитесь, что в `VK_бот/.env` есть строка с токеном:

   ```
   VK_TOKEN=vk1.a....
   ```

2. Проверьте настройки сообщества и токен:

   ```
   venv\Scripts\python.exe VK_бот\diag.py
   ```

   Должны быть `[OK]` для токена, Long Poll API, события
   «Новые сообщения» и Long Poll сервера.

3. Запустите бота:

   ```
   start_bot.bat
   ```

   или вручную:

   ```
   venv\Scripts\python.exe VK_бот\main.py
   ```

4. Напишите сообществу «Начать» — бот пришлёт клавиатуру.

Логи пишутся в консоль и в `VK_бот/bot.log`.

## Настройки сообщества ВК

В «Управлении сообществом»:

1. **Сообщения → Сообщения сообщества** — включить.
2. **Сообщения → Настройки для бота → Возможности ботов** — включить.
3. **Сообщения → Настройки для бота → Long Poll API** — включить,
   версия API 5.199 (или актуальная).
4. В подписках на события включить:
   - `message_new` — новые сообщения;
   - `message_reply` — ответы;
   - `message_edit` — изменение сообщений.
5. **Настройки → Работа с API → Ключи доступа** — создать ключ
   с доступом к сообщениям сообщества и положить его в `.env`.
6. При желании задайте приветственное сообщение с кнопкой «Начать».

Проверить всё это автоматически можно через `diag.py`.

## Что было исправлено

При разборе проекта найдены и устранены ошибки, из-за которых бот
не работал:

1. **Несовместимость с vkbottle 4.11.** `Keyboard.add()` в этой версии
   принимает только одну кнопку, а код вызывал `kb.add(*row)`.
   При выборе системы бот падал с `TypeError` и не присылал клавиатуру
   единиц. Теперь кнопки добавляются по одной.
2. **Кнопки единиц не работали.** Правило `PayloadRule({"unit": str})`
   сравнивает payload целиком и никогда не совпадает с
   `{"unit": "km"}`. Добавлено собственное `UnitPayloadRule`.
3. **`message.payload` — это JSON-строка, а не dict.** Код вызывал
   `message.payload.get(...)`, что дало бы `AttributeError`.
   Теперь используется `message.get_payload_json()`.
4. **Токен был захардкожен в трёх файлах.** Вынесен в `.env`;
   диагностические скрипты берут его оттуда же. Если токен попадал
   в git/переписку — перевыпустите его.
5. **Виртуальное окружение было пустым** — `vkbottle` не установлен.
   Зависимости установлены, версия зафиксирована в `requirements.txt`.
6. **Нет проверки входных данных.** Неизвестная единица или payload
   от старой клавиатуры вызывали `KeyError`; `nan`/`inf` принимались
   как числа. Добавлена валидация.
7. **Числа с запятой не принимались.** `float("5,5")` падал.
   Теперь поддерживаются `5,5`, `1 000`, `−3`.
8. **Плохое форматирование результатов.** `1 мм → км` показывался
   как `0`, потому что число обрезалось до 6 знаков. Добавлено
   аккуратное форматирование.
9. **Команды «помощь» и «начать» смешивались**, а любое сообщение вне
   сценария получало ответ «Отправьте «начать»». Теперь есть помощь,
   подсказки и отдельная обработка ошибок.
10. **Не было обработчика исключений и логов в файл.** Добавлены
    глобальный error handler и `bot.log`.

## Возможные проблемы

| Симптом | Что проверить |
|---|---|
| `[FAIL] VK_TOKEN не найден` | Файл `.env` лежит в `VK_бот/`, строка `VK_TOKEN=...` |
| `Токен не подошёл` | Ключ отключён/перевыпущен, либо это токен пользователя, а не сообщества |
| Бот запущен, но не отвечает | Long Poll API и `message_new` включены; `diag_poll.py` показывает события |
| `failed=1` в Long Poll | Ключ/ts устарели — перезапустите бота, он обновит состояние |
| Ответов нет в беседе | В беседах боту нужно упоминание (`@club...`) |

Long Poll не требует проброса портов, но процесс должен быть запущен
постоянно. Для сервера используйте `systemd`/`NSSM`/Планировщик задач
Windows, чтобы бот перезапускался после сбоев.
